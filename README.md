# ChatPH

ChatPH is a social media web app where people can create posts, connect with others, and send each other messages.

🔗 **Live demo:** https://bryangablao.github.io/ChatPH/

---

## About

ChatPH is built as a simple, friendly social platform for Filipinos and anyone who wants a place to share updates and chat. Users can post to a shared feed and message each other directly, all from the browser.

## Features

- 📝 **Posts** – share updates, thoughts, and moments with other users
- 💬 **Messaging** – send messages to other users
- 👤 **User profiles** – a personal space for each user
- 📰 **Feed** – see what others have posted
- 📱 **Responsive design** – works on desktop and mobile browsers

## Getting Started

### Use it online

Open the live app: https://bryangablao.github.io/ChatPH/

### Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/bryangablao/ChatPH.git
   ```
2. Go into the project folder:
   ```bash
   cd ChatPH
   ```
3. Open `index.html` in your browser, or serve it with a local server:
   ```bash
   npx serve
   ```
